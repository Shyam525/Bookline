# Bookline Customer Directory & CRM Documentation

## Client Profile & Lifetime Metrics

Bookline's CRM tracks client profiles and lifetime analytics per organization tenant.

### CRM Capabilities
- **Client Directory**: Paged search across client names, emails, and phone numbers.
- **Lifetime Value Tracking**:
  - `TotalBookingsCount`: Aggregate count of completed appointments.
  - `TotalSpentAmount`: Lifetime monetary value spent by client.
- **Internal Preferences**: Dedicated notes field for staff preferences, allergies, and custom instructions.
- **Client Detail Drawer**: Rich side panel for inspecting client metrics and history.
