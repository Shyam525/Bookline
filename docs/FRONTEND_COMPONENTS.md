# Frontend Operations Workspace Components

## Workspace Pages Summary
- **Calendar Workspace (`/app/calendar`)**: Multi-view Day/Week/Month projections with appointment status tags & details drawer.
- **Notifications Engine (`/app/notifications`)**: Delivery history logs table, tenant sender configuration form, live test notification modal.
- **Payments Workspace (`/app/payments`)**: Financial KPI summary cards, filterable transactions data table, in-store POS modal, refund modal.
